Agent Awake

Your Mac stays awake while your agents work.

When the last one finishes, it sleeps again. Agent Awake pings your phone if you are away.

ch 1 · trip

One trip in a bag

Version 0.1.2, 75 minutes in a bag. The battery went from 100% to 59%. macOS’s own heat level stayed nominal the whole time, so the app now reads the battery too.

Readings
ReadingMinuteBatterymacOS thermal level
Start0100%nominal
End7559%nominal

100 − 59 = 41 points in 75 minutes. 41 ÷ 1.25 h = 32.8% an hour on average.

Four stop rules

Lid-closed mode gives sleep back to macOS when any of these holds. Point at one to see its mark on the strip.

ch 2 · behaviour

What it does

It keeps the Mac awake only while an agent is working. When the last agent stops, normal sleep comes back. The screen still turns off and locks.

When an agent needs you, the Mac stays awake 15 more minutes, then sleeps.

A quiet agent that is still running a build keeps the Mac awake. One whose process exited is let go.

ch 4 · hooks

Hooks never block an agent

The hooks print nothing and exit at once. If the app is not running, they do nothing.

ch 5 · pings

Pings

Pings go to your phone only while you are away from the Mac: idle, locked or lid closed. At the Mac you get a Mac notification.

Send them to ntfy, Bark, Pushover, Telegram, Discord or Slack. By default a ping names only the agent and the project folder.

ch 6 · lid

Lid closed, in a bag

Lid-closed mode is off by default. You approve its helper once, in System Settings → Login Items.

It gives sleep back to macOS at 10% battery, when the thermal state is serious, above battery 41 °C, or on drain faster than 20% an hour. If the lid is closed when it gives up, the Mac sleeps, and lid-closed mode stays off until the lid opens.

The 41 °C limit comes from two days of the author’s log on a MacBook Pro M4 Pro: 33–38 °C at a desk, 42–43.5 °C in a bag.
